# StreamFlow Pro 🎬

**Take control of every video on the web.** Universal speed control, persistent volume, A-B loop, frame stepping, audio EQ, picture-in-picture, and more — all in one sleek popup.

![Version](https://img.shields.io/badge/version-2.8.4-blue)
![Platform](https://img.shields.io/badge/platform-Chrome-green)
![Manifest](https://img.shields.io/badge/manifest-V3-orange)

## ✨ Features

- **⚡ Universal speed control** — 0.25x to 3.5x on any HTML5 video, remembered across every site
- **🔊 Persistent volume** — your volume stays exactly where you set it, even after seeking
- **⏯️ Full transport controls** — play/pause, ±10s seek, +30s skip, all from the popup
- **🖼️ Picture-in-Picture** — pop any video out into a floating window with one click
- **🔁 A-B loop** — repeat any section of a video, perfect for learning and practice
- **🎞️ Frame stepping** — move frame-by-frame forward or backward
- **📸 Screenshot** — capture any video frame instantly
- **🎚️ 10-band audio equalizer** — presets plus custom tuning, with volume boost past 100%
- **📺 Force HD** — always play YouTube at the highest available quality
- **🚫 Autoplay & ad handling** — auto-unmute, autoplay blocking, and Turbo Ad-Skipper
- **⌨️ Full keyboard shortcuts** — control everything without touching the mouse
- **🔖 Watch Later** — save videos to revisit anytime
- **🌙 Dark mode popup** — easy on the eyes

## ⌨️ Keyboard shortcuts

| Keys | Action |
|------|--------|
| `Space` | Play / Pause |
| `←` / `→` | Seek −10s / +10s |
| `Shift` + `+` / `−` | Speed up / down (0.25x–3.5x) |
| `+` / `−` | Volume up / down |
| `R` | Reset speed to 1.0x |
| `M` | Mute / Unmute |
| `F` | Fullscreen |
| `,` / `.` | Step one frame back / forward |
| `[` / `]` | Set A-B loop start / end |
| `\` | Clear A-B loop |
| `S` | Capture screenshot |

*Shortcuts work when a video is focused and you're not typing in a text field.*

## 📦 Installation

### Load unpacked (for testing & development)
1. Download or clone this repo
2. Open `chrome://extensions` in Chrome
3. Enable **Developer mode** (toggle, top right)
4. Click **Load unpacked** and select the repo folder
5. The StreamFlow Pro icon appears in your toolbar 🎉

## 🔒 Privacy

StreamFlow Pro respects your privacy:

- All settings are stored **locally** in your browser (`chrome.storage`) — nothing is uploaded anywhere
- No accounts, no tracking, no analytics
- The extension only activates its video controls on pages you visit; it never reads page content beyond finding video elements
